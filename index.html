Agent Orchestration

Multi-agent supervision with task decomposition, a typed IPC bridge, and execution monitoring — a supervisor routes work to the right worker.

Skills System

13+ built-in skills (code review, debugging, research, testing) plus a registry, loader, and CLI for custom skills you author yourself.

CRM Intelligence Suite

Company/contact enrichment, deal and thread tracking, brand analysis and fact recording — 18 skills, with local and API-key gated sourcing.

Local-First Inference

Streaming support for Ollama, LM Studio, KoboldCPP, and LlamaCPP. No data leaves your machine unless you add a provider.

CRM Integration Suite

The CRM capability was ported from the Eve/CRM TypeScript codebase. The repo interface exposes company/contact/discussion tracking, enrichment, and fact recording. system/capabilities.py gates skills so only what you own stays local.

Download & Install

Three paths: Windows (NSIS or portable), Linux (AppImage / deb / rpm), Docker for containerized runs. See the README for system requirements and environment setup.

  • Windows — NSIS installer or portable build (electron-builder)
  • Linux — AppImage, deb, or rpm
  • Containers — docker-compose.yml, Dockerfile & Dockerfile.production

FAQ

What data leaves my machine?
Local models stay on device. Only the web-research skills (DuckDuckGo) and any API-key-gated skills (enrichment, LinkedIn) send data — and only when you provide the key.
Which models does this support?
Ollama, LM Studio, KoboldCPP, and LlamaCPP, with streaming and thinking traces.
Can I use my own CRM?
This is a standalone desktop app bundled with its own CRM intelligence suite. Third-party CRM connectors are not yet documented.
Is it open source?
See the repository's LICENSE file and the third-party integrations (OpenDAN, Skills_2026, AutoPentestX, Voice Processing).
